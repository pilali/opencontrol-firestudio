Installation complete

  1. If macOS reports a blocked system extension, open System Preferences › Security & Privacy, allow “PreSonus Software Limited”, then restart.
  2. Connect and power on the FireStudio, then launch OpenControl from the Applications folder.
  3. On every connection the app backs up the full device state to ~/Library/Application Support/OpenControl/Backups.

Documentation and issue tracker: github.com/pilali/opencontrol-firestudio
